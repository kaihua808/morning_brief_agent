# 基金晨报 MVP 定义

> 版本：v0.1
> 首只基金：006131｜华泰柏瑞沪深300ETF联接C
> 阅读目标：3 分钟内完成
> 产品定位：研究辅助工具，不是交易决策工具

## 一、背景与用户问题

过去投资时容易集中关注医药、电池等单一板块，并在板块上涨后产生追高倾向；同时缺少判断行业趋势的方法，容易根据短期涨跌作出情绪化判断。

开始关注沪深300等宽基后，新的问题是：虽然每天能够看到涨跌，但无法判断它只是单日波动，还是近期变化的一部分，也不知道风险是否正在扩大。

本产品要解决的不是“预测明天涨跌”，而是：

```text
把看到涨跌就判断，变成看到结构化证据后再进入研究。
```

## 二、目标用户

当前目标用户只有一人：基金持有人本人。

用户特点：

- 具备基础基金投资经验；
- 曾经有追逐热门板块和追高的倾向；
- 不会每天进行专业研究；
- 希望用较短时间理解基金近期变化；
- 正在学习基金指标、Python 和 AI Agent。

## 三、用户故事

```text
作为一个曾经容易追逐热门板块的基金初学者，
我希望每天看到沪深300基金的结构化变化和风险，
从而区分单日波动与持续变化，减少情绪化操作。
```

## 四、为什么选择 006131

- 属于本人真实持有的基金；
- 跟踪沪深300，研究对象和比较基准明确；
- 历史数据相对充足，适合计算短期变化和回撤；
- 宽基比单一行业更适合建立第一套通用分析框架；
- 数据与结论更容易复核，适合作为第一个 MVP。

选择 006131 是为了验证产品和分析框架，不代表它是投资建议或收益最优的基金。

## 五、产品目标

每天使用最新可确认的交易日数据，在 3 分钟内回答：

1. 数据是否最新、完整？
2. 最近一个交易日发生了什么？
3. 单日变化与近 5 日、近 20 日变化是否一致？
4. 近期风险是否扩大？
5. 基金与沪深300指数之间是否出现明显差异？
6. 当前只需正常观察，还是需要进一步研究？

## 六、输入数据

### 基金信息

- 基金代码；
- 基金名称；
- 基金类型；
- 跟踪指数。

### 净值数据

- 数据日期；
- 历史单位净值；
- 累计净值或经过分红调整的数据；
- 日增长率。

### 比较基准

- 沪深300指数的同期历史数据。

正式数据源将在数据实验阶段验证并记录。任何输出都必须显示数据日期和来源。

## 七、确定性指标

以下指标由 Python 计算，Model 不自行心算：

| 指标 | 解决的问题 |
|---|---|
| 最新单位净值 | 最新确认的每份基金价值是多少 |
| 单日变化 | 最近一个交易日发生了什么 |
| 近 5 日变化 | 最近一周的大致变化 |
| 近 20 日变化 | 最近一个交易月的大致变化 |
| 近 20 日最高、最低值 | 最近区间的上下边界 |
| 近 20 日区间位置 | 当前更靠近近期高位还是低位 |
| 近 20 日最大回撤 | 从阶段高点出发最多下跌了多少 |
| 沪深300同期变化 | 比较基准同期表现如何 |
| 基金与指数的差异 | 是否需要检查数据或跟踪偏离 |

区间位置公式：

```text
(最新净值 - 20日最低净值) ÷ (20日最高净值 - 20日最低净值)
```

区间位置只表示当前值在近 20 日范围中的相对位置，不代表估值高低，也不直接产生买卖结论。

最大回撤必须考虑时间顺序：先出现阶段高点，之后才计算从高点到低点的最大跌幅。

## 八、三分钟晨报输出

### 1. 数据是否可靠

- 数据日期；
- 最新单位净值；
- 上一交易日净值；
- 数据来源；
- 数据状态：正常、延迟或缺失；
- Python 计算状态。

如果数据不是最新可确认交易日，或存在关键字段缺失，应先提示异常，不继续生成确定性解读。

### 2. 发生了什么

展示：

- 单日变化；
- 近 5 日变化；
- 近 20 日变化；
- 三个时间窗口之间的关系。

示例：

```text
单日上涨，但近 5 日和近 20 日仍然下跌。
目前只能确认最近一个交易日出现反弹，不能说明中短期方向已经改变。
```

### 3. 风险情况

展示：

- 近 20 日最高净值；
- 近 20 日最低净值；
- 当前区间位置；
- 近 20 日最大回撤。

解释只能描述近期位置与历史风险，不把“靠近低位”解释为应该买入，也不把“靠近高位”解释为应该卖出。

### 4. 与沪深300比较

展示：

- 基金近 20 日变化；
- 沪深300近 20 日变化；
- 两者差异；
- 数据日期是否一致。

差异明显时，只提示检查数据、费用、现金仓位或跟踪误差，不由 Model 猜测原因。

### 5. 今日结论

输出一至两句只基于数据的客观总结，并给出一个状态标签：

- 正常观察；
- 短期变化明显；
- 风险有所扩大；
- 数据异常需检查。

各标签的具体阈值要在获得真实数据后确定，本阶段不凭感觉硬编码。

### 6. 行为提醒

- 是否只因为单日上涨而产生追加冲动；
- 是否只因为单日下跌而产生赎回冲动；
- 是否存在需要进一步研究的问题。

行为提醒由用户自行确认，Agent 不替用户作出交易决定。

## 九、Agent 工作链路

```text
基金代码
→ 数据工具读取净值和指数数据
→ Python 验证日期与字段
→ Python 计算确定性指标
→ 将结构化结果返回 Model
→ Model 解释指标之间的关系
→ 程序校验关键数字和结论
→ 生成三分钟晨报
```

职责边界：

- 数据工具：获取真实数据；
- Python：清洗、校验和计算；
- Model：解释数据、组织语言；
- 用户：决定是否继续研究，以及是否采取个人行动。

## 十、成功标准

### 功能成功

- 可以针对 006131 重复生成晨报；
- 正常数据、延迟数据和缺失数据都有明确处理；
- 所有确定性数字均由 Python 计算；
- Model 输出中的日期和数字与工具结果一致。

### 使用成功

- 正文可以在 3 分钟内读完；
- 用户能够区分单日、5 日和 20 日变化；
- 用户能够理解区间位置和最大回撤；
- 晨报能提醒用户避免仅根据单日涨跌追涨杀跌。

### 安全边界

- 不预测确定收益；
- 不输出直接的买入或卖出指令；
- 不连接真实交易账户；
- 不自动执行交易；
- 不把模型生成内容伪装成实时数据。

## 十一、本版本不做什么

- 不同时分析全部基金；
- 不做自动交易；
- 不给出仓位比例建议；
- 不预测第二天涨跌；
- 不加入新闻情绪；
- 不加入宏观经济预测；
- 不加入估值分位；
- 不实现长期记忆、RAG 或 Multi-Agent；
- 不实现自动邮件和定时发送。

## 十二、已知风险与待验证问题

- 场外 ETF 联接基金净值不是盘中实时价格；
- 最新可用数据可能是前一个交易日的数据；
- 单位净值可能受到分红影响，需要确认长期收益计算口径；
- 基金与指数的数据日期必须对齐；
- 数据接口可能出现延迟、缺失或字段变化；
- 状态标签阈值需要通过真实数据和 badcase 验证。
