# 基金晨报指标概念与算法

这份文档解释 `fund_metrics.py` 使用的基金概念、计算方法和数据状态。它用于学习与项目说明，不构成投资建议。

## 一、数据基础

### 单位净值（NAV）

单位净值表示每一份基金在某个净值日期对应的价值。本项目使用单位净值计算历史变化，不使用实时成交价格。

代码中的 `nav_values` 是按日期从早到晚排列的单位净值列表：

```python
nav_values = fund_df["单位净值"].tolist()
```

只有先按日期升序排列，`nav_values[-1]` 才表示最新净值。

### 数据日期与参考日期

- `data_date`：CSV 中最新一条净值的日期。
- `reference_date`：程序判断数据是否过期时使用的日期。
- `age_calendar_days`：参考日期减去数据日期得到的自然日差。
- `freshness_basis = "calendar_days"`：明确当前使用自然日，而不是交易日判断新鲜度。

当前 MVP 规则：

```text
相差 0～4 个自然日 → normal
相差超过 4 个自然日 → delayed
数据日期晚于参考日期 → invalid
```

## 二、区间变化

区间变化用于描述净值在一段时间内上涨或下跌了多少。

公式：

```text
区间变化率 = (结束净值 ÷ 开始净值 - 1) × 100%
```

例如净值从 `1.00` 上涨到 `1.05`：

```text
(1.05 ÷ 1.00 - 1) × 100% = 5.00%
```

对应函数：

```python
calculate_period_change(nav_values, trading_days)
```

计算近 5 日变化需要当前净值和 5 个交易日前的净值，因此至少需要 6 个净值点；计算近 20 日变化需要至少 21 个净值点。

区间变化只描述历史表现，不能预测下一交易日涨跌。

## 三、区间最高值、最低值与区间位置

- `highest_20d`：最近 20 条净值中的最高值。
- `lowest_20d`：最近 20 条净值中的最低值。
- `position_20d_percent`：最新净值处在最高值和最低值之间的相对位置。

区间位置公式：

```text
(当前净值 - 最低值) ÷ (最高值 - 最低值) × 100%
```

解释：

- 接近 `0%`：当前净值接近区间最低值。
- 接近 `50%`：当前净值位于区间中部。
- 接近 `100%`：当前净值接近区间最高值。

例如区间最低值为 `1.00`、最高值为 `1.20`、当前值为 `1.10`：

```text
(1.10 - 1.00) ÷ (1.20 - 1.00) × 100% = 50%
```

如果最高值和最低值相同，分母为零，函数会抛出 `ValueError`，拒绝生成没有意义的区间位置。

区间位置高不等于未来一定下跌，位置低也不等于适合买入。

## 四、最大回撤

最大回撤表示在给定历史区间内，从某个阶段高点到它之后低点出现过的最大跌幅。

关键点是时间顺序：必须先出现高点，再出现低点。

例如：

```text
[1.00, 1.20, 1.10, 0.90, 1.15]
```

阶段高点为 `1.20`，之后最低跌到 `0.90`：

```text
(0.90 ÷ 1.20 - 1) × 100% = -25.00%
```

但下面的数据最大回撤是 `0%`：

```text
[0.90, 1.20]
```

因为低点先出现，之后只有上涨，不能倒过来把两者计算成回撤。

本项目的算法过程：

```text
从左到右读取净值
→ 保存截至当前见过的阶段最高值
→ 计算当前值相对阶段最高值的跌幅
→ 保留最负的那次跌幅
```

对应函数：

```python
calculate_max_drawdown(nav_values)
```

最大回撤描述历史区间中的下跌风险，不代表未来一定会重复同样的跌幅。

## 五、数据状态

`data_status` 描述输入数据是否可信：

| 状态 | 含义 | 程序行为 |
|---|---|---|
| `normal` | 数据通过全部校验且日期在允许范围内 | 计算并返回指标 |
| `delayed` | 数据日期距离参考日期超过 4 个自然日 | 阻止计算 |
| `missing` | 文件、必要字段或具体数值缺失 | 阻止计算 |
| `insufficient` | 有效记录少于 21 条 | 阻止计算 |
| `invalid` | 基金代码、日期格式、净值格式、非正净值或日期逻辑不可信 | 阻止计算 |

`calculation_status` 描述计算是否执行：

- `completed`：指标已计算完成。
- `blocked`：数据校验没有通过，指标为 `None`。

两类状态分开，可以区分“数据有什么问题”和“计算有没有执行”。

## 六、程序职责边界

```text
CSV / pandas → 读取和整理数据
Python       → 校验数据并计算确定性指标
Model        → 后续只解释 Python 返回的结构化结果
用户         → 根据晨报自行判断，不由程序自动交易
```

当前版本不预测涨跌、不提供买卖建议，也不自动执行交易。

## 七、当前已知限制

1. 新鲜度按自然日判断，春节、国庆等长假可能把合法数据误判为延迟。
2. 本地 CSV 是实验样例，不代表实时行情。
3. 近 20 日高低值、区间位置和最大回撤使用最近 20 条净值记录；近 20 日变化需要 21 条记录作为起点和终点。
